# ПО Ремонт

**ПО Ремонт — мобильное приложение для контроля качества ремонта.**

Приложение помогает организовать приёмку работ по помещениям и этапам: пройти чек-листы, зафиксировать дефекты с фотографиями, оценить общий прогресс и сформировать PDF-отчёт. Данные хранятся локально на устройстве, а встроенный справочник доступен без подключения к сети.

## Возможности

- создание проекта с набором помещений и этапов ремонта;
- пошаговые чек-листы с фиксацией результата каждой проверки;
- регистрация и редактирование дефектов, статусов и комментариев;
- добавление до двух фотографий из камеры или галереи;
- сводная панель с прогрессом по помещениям и количеством дефектов;
- общий список замечаний с фильтрацией по помещению;
- формирование PDF-отчёта с описаниями и фотографиями;
- встроенный справочник по материалам и технологиям с поиском.

Подробное описание: [docs/FEATURES.md](docs/FEATURES.md).

## Технологии

- Kotlin;
- Jetpack Compose и Material 3;
- Navigation Compose;
- Room и SharedPreferences для локального хранения;
- Android Activity Result API для камеры и выбора изображений;
- Coil для отображения фотографий;
- Android `PdfDocument` для формирования отчётов;
- Gradle Kotlin DSL и KSP.

## Требования

- JDK 17;
- Android SDK Platform 34;
- Android Studio с установленным Android SDK;
- устройство или эмулятор с Android 7.0 (API 24) или новее.

## Сборка

После клонирования откройте проект в Android Studio и дождитесь синхронизации Gradle. Если путь к SDK не определён автоматически, создайте локальный файл `local.properties`:

```properties
sdk.dir=C\:\\path\\to\\Android\\Sdk
```

Debug-сборка в Windows:

```powershell
.\gradlew.bat :app:assembleDebug
```

В macOS или Linux:

```bash
./gradlew :app:assembleDebug
```

APK будет создан в `app/build/outputs/apk/debug/`. Каталоги сборки, настройки среды разработки, локальный путь SDK и готовые пакеты исключены из Git.
