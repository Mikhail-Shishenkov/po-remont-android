# Функциональные возможности

## Проект ремонта

Пользователь создаёт локальный проект, выбирает помещения и назначает для каждого помещения этапы работ. Настройка сохраняется между запусками приложения и используется как основа для навигации, расчёта прогресса и группировки замечаний.

## Контроль по этапам

Для каждого выбранного этапа доступен специализированный чек-лист. Пункт проверки можно отметить как выполненный, пропущенный или связанный с дефектом. Экран этапов показывает процент прохождения и число активных замечаний.

Чек-листы охватывают основные виды ремонтных работ, включая подготовку, инженерные системы, черновую и чистовую отделку.

## Дефекты

Карточка дефекта содержит:

- помещение и этап работ;
- наименование замечания;
- подробное описание;
- статус: дефект, исправлено или пропущено;
- до двух фотографий.

Карточку можно создать непосредственно из пункта чек-листа, затем открыть для редактирования. Фотографии добавляются с камеры или выбираются из галереи. Общий список дефектов поддерживает просмотр по конкретному помещению или по всему проекту и показывает статистику по статусам.

## Сводная панель

Сводный экран объединяет текущее состояние проекта:

- общий прогресс проверки;
- прогресс каждого помещения;
- количество активных дефектов;
- быстрый переход к этапам, замечаниям и справочнику.

Прогресс рассчитывается по сохранённым статусам пунктов чек-листа.

## PDF-отчёт

Из списка дефектов формируется локальный многостраничный PDF-отчёт. В него входят сведения о проекте, помещение и этап, статус замечания, текстовое описание и прикреплённые фотографии. Разметка автоматически переносит карточки между страницами и сохраняет читаемую структуру документа.

## Справочник

Встроенный справочник загружается из `app/src/main/assets/reference/materials.json` и работает без сети. Он поддерживает:

- иерархию разделов и материалов;
- полнотекстовый поиск по названиям и содержимому;
- текстовые блоки, списки и таблицы;
- просмотр отдельного материала;
- локальную замену каталога и возврат к встроенной версии.

## Локальная работа

Приложение не зависит от внешнего сервера. Конфигурация проекта, результаты проверок и дефекты хранятся на устройстве. Снимки камеры сохраняются во внутреннем хранилище приложения, а доступ к выбранным изображениям галереи закрепляется средствами Android.
